# Assets & Maps
This file serves as a guide to the visual resources available in this wiki. 

## Key Visuals
*   **World Map:** See `assets/world_map_v1.png`
*   **NPC Portraits:** Located in the `/characters/portraits` sub-folder (to be created).
*   **Item Icons:** Standardized icons for all loot are located in the `/items/icons` folder.

## Style Guide
All images should follow the "Glassmorphism" aesthetic—soft edges, high transparency, and muted colors to maintain the wiki's vibe.
